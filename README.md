# Smart Energy Meter

## Project Overview
ESP32-based Smart Energy Meter developed as part of an Embedded Systems Internship.

## Features
- 4-cell battery monitoring
- Average voltage calculation
- Weakest and strongest cell detection
- Battery health classification
- Safety protection
- Relay and buzzer protection
- Fault detection and recovery
- LCD diagnostic interface
- Blynk cloud telemetry
- Event queue for network recovery
- Executive battery dashboard

## Technologies Used
- ESP32
- Arduino IDE
- Wokwi
- Blynk IoT
- C/C++
